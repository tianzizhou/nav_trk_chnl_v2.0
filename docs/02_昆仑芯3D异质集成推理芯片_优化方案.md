## 一、项目概述

### 1.1 项目定位

基于国产工艺链的3D异质集成存算一体AI推理芯片，采用分阶段递进策略，突破"存储墙"与供应链"卡脖子"双重困局。

### 1.2 核心目标（分阶段）

| 阶段 | 时间节点 | 参数规模 | 堆叠层数 | 关键验证目标 |
|------|---------|---------|---------|-------------|
| Phase-1 验证版 | 2027 Q4 | 20B | 4层 | CIM功能验证、WoW键合工艺验证 |
| Phase-2 产品版 | 2028 Q4 | 50-100B | 8层 | 量产良率优化、散热方案验证 |
| Phase-3 旗舰版 | 2030+ | 200B+（单芯片） | 16层 | 密度突破、系统级扩展至1T |

### 1.3 核心理念

- **逻辑用中芯N+1保算力**：采用国产最先进逻辑工艺，实现高效计算核心
- **存储用28nm ReRAM破垄断**：利用国产新型非易失存储替代进口HBM/DDR
- **3D堆叠逐步演进**：从4层起步、8层量产、16层突破，稳步推进

## 二、芯片架构设计

### 2.1 整体架构：三层解耦式3D架构

```
┌────────────────────────────────────────────────────────────────┐
│  散热顶盖 + 微流道冷却层（可选，Phase-2引入）                │
├────────────────────────────────────────────────────────────────┤
│  Layer 0: 逻辑层（Logic Core）— 中芯N+1工艺                  │
│  ┌──────────────┬───────────────┬──────────────┬────────────┐ │
│  │ MAC阵列集群  │  片上SRAM     │  3D NoC      │  调度器    │ │
│  │ 4×512 MAC    │  128MB        │  控制器      │  APSD+WDOS │ │
│  │ INT4/INT8    │  激活/KV缓存  │  TSV接口     │            │ │
│  └──────────────┴───────────────┴──────────────┴────────────┘ │
├────────────────────────────────────────────────────────────────┤
│             TSV互连层（pitch 9μm, 12,000个/层）               │
│             微凸点键合（5μm pitch）                           │
├────────────────────────────────────────────────────────────────┤
│  Layer 1-N: 28nm ReRAM存储层（N=4/8/16 视阶段而定）          │
│  ┌──────────────────────────────────────────────────────────┐ │
│  │ 每层容量：0.5-1 GB（基于4-8 Gb/cm²密度）                │ │
│  │ 采用昕原"昕·山文"eReRAM IP                              │ │
│  │ 支持现场重编程（模型权重更新）                           │ │
│  │ 集成行/列ECC + 冗余单元                                 │ │
│  │ 每层TSV接口阵列对齐逻辑层                               │ │
│  └──────────────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────────────┘
```

### 2.2 逻辑层详细设计（Layer 0）

#### 2.2.1 计算核心

| 参数 | Phase-1 | Phase-2 | 说明 |
|------|---------|---------|------|
| MAC阵列 | 4×512（2048个MAC） | 4×1024（4096个MAC） | INT4/INT8混合精度 |
| 峰值算力（INT4） | 65.5 TOPS @2GHz | 131 TOPS @2GHz | 基于N+1实际频率评估 |
| 峰值算力（INT8） | 32.8 TOPS | 65.5 TOPS | — |
| 工作频率 | 1.5-2.0 GHz | 1.5-2.0 GHz | 基于中芯N+1保守估计 |

#### 2.2.2 片上存储

| 参数 | 数值 | 说明 |
|------|------|------|
| SRAM容量 | 128 MB | 用于激活值和KV缓存 |
| SRAM面积占比 | ~17%（约100 mm²） | 基于7nm SRAM 10.2 Mbit/mm² |
| 功能划分 | 64MB激活缓存 + 64MB KV缓存 | 可动态分配 |

#### 2.2.3 3D NoC与TSV接口

| 参数 | 数值 | 推导依据 |
|------|------|---------|
| TSV数量 | 12,000个/层 | pitch 9μm |
| 单TSV速率 | 2 Gbps | 保守估计，差分传输可达4G |
| 单层TSV带宽（单向） | 3.0 TB/s | 12,000 × 2 Gbps / 8 |
| 有效带宽（含协议开销） | ~2.4 TB/s | 按80%效率计 |

> **注**：原方案声称16 TB/s带宽不可达。此处基于12,000 TSV × 2Gbps给出工程可达值。如需更高带宽，需将TSV数量提升至30,000+个或采用更高速率。

#### 2.2.4 调度器

- **APSD（Adaptive Parallel Speculative Decoding）**：自适应并行推测解码，根据输入token的困惑度动态调整推测深度
- **WDOS（Weight-Data Orchestration Scheduler）**：权重-数据编排调度器，协调多层ReRAM的读取顺序，最大化层间带宽利用率

### 2.3 存储层详细设计（Layer 1-N）

#### 2.3.1 单层容量估算

| 参数 | 保守值 | 乐观值 | 说明 |
|------|--------|--------|------|
| ReRAM有效面积 | 400 mm²（69%填充率） | 450 mm² | 扣除TSV着陆区+ECC+外围电路 |
| 密度（28nm eReRAM） | 4 Gb/cm² | 8 Gb/cm² | 基于昕原公开数据 |
| 单层原始容量 | 200 Mb（25 MB） | 450 Mb（56 MB） | — |
| 扣除ECC+冗余（20%） | 20 MB | 45 MB | — |

> **对照计算**：20B参数 × 4bit = 10 GB。4层堆叠保守总容量 = 4 × 20 MB = 80 MB，远不足以存放20B参数。

#### 2.3.2 容量问题的解决路径

上述计算揭示了一个核心矛盾：**当前28nm ReRAM的面积密度不足以在580mm²投影面积内存放数十GB权重**。为此，方案采用以下组合策略：

**策略A：提升单层有效密度**

- 采用多值存储（MLC/TLC ReRAM），每个单元存储2-3 bit，密度提升2-3倍
- 昕原eReRAM已展示2bit/cell可行性（实验室阶段），4bit/cell在路线图中
- 使用3D VRRAM（垂直ReRAM）技术，单层内部实现多层堆叠

**策略B：增大投影面积（Reticle拼接）**

- 采用光罩拼接技术，将单die面积扩大至800-1200 mm²
- 中芯N+1支持最大光罩面积约858 mm²（26mm × 33mm）
- 存储层采用28nm工艺，光罩限制更宽松，可做到更大面积

**策略C：外挂HBM/LPDDR作为容量补充**

- 在基板上集成2-4颗国产LPDDR5（长鑫存储）
- 片外存储用于存放冷权重（低频访问层），热权重存放在片上ReRAM
- 引入智能预取引擎，提前将下一层权重从LPDDR加载到ReRAM缓存

**推荐组合方案（Phase-1）**：

| 存储层级 | 容量 | 用途 | 来源 |
|---------|------|------|------|
| L0: 片上SRAM | 128 MB | 激活值、KV缓存 | 逻辑层集成 |
| L1: 4层ReRAM | 320 MB（MLC 2bit） | 热权重（高频访问层） | 3D堆叠 |
| L2: 片外LPDDR5 | 32 GB（4×8GB） | 冷权重 + 全量参数 | 基板集成 |

此方案可支持20B参数模型的推理：热层权重（约5-8B参数的4bit量化 = 2.5-4 GB）中的高频部分在ReRAM中完成CIM，其余通过LPDDR5加载。

### 2.4 散热架构

```
          ↑ 热量散出方向
    ┌─────────────────────┐
    │    散热器/热沉       │
    ├─────────────────────┤
    │  Layer 0: 逻辑层    │ ← 主要热源，距散热器最近
    ├─────────────────────┤
    │  TSV互连 + 键合层   │
    ├─────────────────────┤
    │  Layer 1: ReRAM     │
    ├─────────────────────┤
    │  Layer 2: ReRAM     │
    ├─────────────────────┤
    │  Layer 3: ReRAM     │
    ├─────────────────────┤
    │  Layer 4: ReRAM     │ ← 最远离散热器，但发热量最低
    ├─────────────────────┤
    │  硅中介层（可选）    │
    │  微流道冷却（Phase-2）│
    ├─────────────────────┤
    │  基板（Substrate）   │
    └─────────────────────┘
```

**设计要点**：
- 逻辑层置顶（Flipped），距离散热器最近，散热路径最短
- 存储层静态功耗低（ReRAM读取功耗约0.1-0.5 pJ/bit），发热量有限
- Phase-2引入硅中介层微流道辅助底部散热

## 四、关键技术路线

### 4.1 存算一体（CIM）计算范式

**原理**：利用ReRAM的物理特性（电导 = 权重值），通过施加电压（= 输入激活值）在存储阵列中直接完成矩阵-向量乘法（MVM），无需将数据搬运至独立计算单元。

**优势**：
- 消除权重数据搬运的能耗和延迟
- 计算与存储一体化，能效比提升10-100倍（vs. 传统冯·诺依曼架构）
- 天然适合推理场景（权重固定，仅激活值变化）

**挑战与应对**：

| 挑战 | 应对方案 |
|------|---------|
| ReRAM器件一致性 | 在线校准 + 混合精度补偿 |
| ADC/DAC精度与面积 | 采用SAR ADC，8bit精度，分时复用 |
| 大规模阵列的IR drop | 分块计算（128×128子阵列） + 电流求和补偿 |
| 写入耐久性 | 权重为准静态数据，写入次数极少（仅模型更新时） |

### 4.2 3D WoW堆叠技术

**工艺流程**（以Phase-1四层堆叠为例）：

```
Step 1: 逻辑层晶圆制造（中芯N+1） → KGW测试
Step 2: 存储层晶圆制造（长鑫28nm eReRAM）× 4片 → KGW测试
Step 3: 存储层Layer4（底层）+ Layer3 WoW键合
Step 4: (Layer4+3) + Layer2 WoW键合
Step 5: (Layer4+3+2) + Layer1 WoW键合
Step 6: (存储层4层) + 逻辑层 WoW键合（逻辑层翻转置顶）
Step 7: TSV刻蚀 + 铜填充 + 再布线（RDL）
Step 8: 切割 + 封装（BGA基板）
```

**良率管控**：

| 指标 | Phase-1目标 | Phase-2目标 |
|------|-----------|-----------|
| 单层ReRAM晶圆良率 | ≥95% | ≥97% |
| WoW键合良率（每次） | ≥98% | ≥99% |
| 4层堆叠总良率 | ≥82% | ≥89% |
| 8层堆叠总良率 | — | ≥80% |

**KGW（Known Good Wafer）策略**：在每次键合前对晶圆进行全面测试，仅将合格晶圆进入下一步键合，避免不良晶圆的浪费。

### 4.4 调度算法

#### APSD（Adaptive Parallel Speculative Decoding）

```
输入: 待推理序列 X, 主模型 M, 草稿模型 M_draft
参数: 推测深度 K（动态调整）

while not end_of_sequence:
    1. 困惑度估算: perplexity = estimate(X_current)
    2. 动态调整K:
       - if perplexity < threshold_low:  K = K_max (高确信，多推测)
       - if perplexity > threshold_high: K = 1     (低确信，逐token)
       - else: K = interpolate(perplexity)
    3. 草稿模型生成K个候选token
    4. 主模型并行验证K个候选
    5. 接受连续正确的前缀，拒绝后续
    6. 更新X_current
```

**预期收益**（基于睿科ISSCC 2026论文数据）：
- 吞吐提升：1.29×
- 拒绝率降低：14%
- 硬件利用率：≥99%

#### WDOS（Weight-Data Orchestration Scheduler）

- 根据Transformer层的访问模式，预调度ReRAM各层的读取顺序
- 流水线化层间数据传输，隐藏TSV传输延迟
- 动态功率管理：未被访问的ReRAM层进入低功耗待机状态

## 九、结语

本方案以**工程可行性为第一原则**，将原始1T参数的单芯片目标调整为分阶段递进路线：

- **Phase-1**（20B参数/4层堆叠）：验证CIM+3D堆叠的核心技术可行性
- **Phase-2**（50-100B参数/8层堆叠）：推向产品化和小规模量产
- **Phase-3**（200B+参数/16层堆叠+多芯片扩展至1T）：实现终极目标

每个阶段都建立在前一阶段的验证成果之上，降低技术和投资风险。最终目标不变——通过全国产化的存算一体芯片，为中国AI产业提供自主可控的推理算力底座。

> *"架构创新不是一步登天，而是每一步都站稳脚跟。*  
> *从4层到8层到16层，从20B到100B到1T——*  
> *稳步攀登，昆仑可期。"*

## 附录A 参数推导与计算依据

### A.1 ReRAM容量密度推导

当前28nm ReRAM（SLC模式）的公开数据显示面积密度约为2-4 Gb/cm²。取中间值3 Gb/cm²：

- 投影面积580 mm² = 5.8 cm²
- 扣除TSV着陆区、ECC、外围电路，有效面积比约为70%
- 有效面积 = 5.8 × 0.7 = 4.06 cm²
- 单层原始容量 = 4.06 × 3 = 12.18 Gb = 1.52 GB（SLC）

采用MLC（2bit/cell）模式：

- 单层容量 = 1.52 × 2 = 3.04 GB（理论值）
- 扣除20% ECC+冗余 = 2.43 GB
- 考虑MLC良率折损（约70%有效率）= 1.70 GB

> 注：以上为理论推导，MLC ReRAM的量产良率和一致性仍在验证中。Phase-1按保守值80MB/层（纯SLC+高冗余）设计，随工艺成熟逐步提升。

### A.2 TSV带宽计算

- TSV数量：12,000个/层
- 数据TSV占比：约60%（其余为电源、地线、冗余）
- 有效数据TSV：7,200个
- 单TSV数据速率：2 Gbps（保守值）
- 原始带宽 = 7,200 × 2 Gbps = 14.4 Tbps = 1.8 TB/s
- 含协议开销后有效带宽 ≈ 1.4 TB/s

> 如采用差分TSV（2根TSV为一对），有效数据通道减半但速率可提升至4Gbps/对，总带宽基本持平，但信号完整性显著改善。

### A.3 功耗分解

**Phase-1（TDP 150W）**：

| 模块 | 功耗（W） | 占比 |
|------|----------|------|
| MAC阵列 | 60 | 40% |
| SRAM（128MB） | 25 | 17% |
| NoC + 调度器 | 15 | 10% |
| IO + PHY | 10 | 7% |
| 逻辑层其他 | 10 | 7% |
| ReRAM存储层（4层） | 20 | 13% |
| TSV驱动 | 5 | 3% |
| 余量 | 5 | 3% |
| **合计** | **150** | **100%** |

功耗密度 = 150W / 5.8cm² = 25.9 W/cm²，在风冷安全阈值（~40 W/cm²）内。
